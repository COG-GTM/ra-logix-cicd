Build output (bin\ and obj\ folders) is not stored in this repository. The CI and CD Jenkins pipelines compile their C# solutions from source in a
'Build' stage (dotnet publish --configuration Release) and run the freshly built executable from a folder outside the repository checkout.
The pipelines stop if any bin\ or obj\ file is committed. Build the solutions locally with Visual Studio or dotnet build to run them by hand.
